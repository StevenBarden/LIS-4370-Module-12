# Social Network Visualization in R

## Overview
This project for LIS-4370 Module 12 creates a social network visualization using RStudio and ggnet2. It generates a random network with 10 nodes, visualizes it, and reports results.

## Requirements
- RStudio
- Packages: GGally, network, sna, ggplot2

## How to Run
1. Clone the repo.
2. Open `LIS4370Week12code.R` in RStudio.
3. Set `baseDir` to your directory.
4. Run the script: `source("LIS4370Week12code.R")`.

## Output
- Network: 10 nodes, 27 edges.
- Visualization: [RPlot Image](https://outlync.wordpress.com/wp-content/uploads/2025/04/rplot.png?w=300)
- Log: Check `script_log.txt` in your directory.
